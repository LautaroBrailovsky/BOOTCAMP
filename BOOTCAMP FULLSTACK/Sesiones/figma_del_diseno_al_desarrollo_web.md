# Figma: del diseño al desarrollo web

## ¿Qué es Figma?

**Figma** es una herramienta que utilizan principalmente los **UX/UI Designers** para diseñar aplicaciones y páginas web.

Un diseñador puede utilizar Figma para:

- Diseñar visualmente una página web o una aplicación.
- Decidir dónde colocar los elementos.
- Definir colores, tamaños, tipografías, imágenes, botones, etc.
- Crear diferentes pantallas y versiones para ordenador y móvil.
- Crear **prototipos**, conectando unas pantallas con otras para simular cómo funcionaría la aplicación.

Por ejemplo, un diseñador puede crear:

> Página de inicio → Productos → Detalle del producto → Carrito

y hacer que podamos pulsar sobre los botones para navegar entre ellas.

---

## ¿Cómo se utiliza Figma en un equipo de desarrollo?

En un proyecto profesional suelen trabajar diferentes perfiles.

Un proceso sencillo podría ser:

```text
Idea
  ↓
Diseño en Figma
  ↓
Prototipo
  ↓
Desarrolladores Frontend
  ↓
HTML + CSS + JavaScript
  ↓
Aplicación web
```

Primero se define cómo será la aplicación y se crea su diseño.

Después, ese diseño pasa a los **developers**, que se encargan de convertirlo en una aplicación real.

En nuestro caso, nosotros seremos los **desarrolladores frontend**.

Nuestro trabajo será convertir un diseño como este:

> Diseño visual en Figma

en algo que funcione realmente en el navegador:

> HTML + CSS + JavaScript

---

## Figma como referencia para nuestros proyectos

Durante el curso podemos utilizar diseños de Figma como referencia para practicar.

La idea es intentar reproducir un diseño utilizando HTML, CSS y JavaScript.

No es necesario copiar exactamente todos los detalles. Lo importante es aprender a:

1. Observar un diseño.
2. Identificar sus diferentes partes.
3. Pensar qué elementos HTML necesitamos.
4. Crear la estructura HTML.
5. Aplicar CSS para conseguir un resultado parecido.
6. Adaptarlo a diferentes tamaños de pantalla.

Figma también nos permite consultar diferentes propiedades de los elementos y obtener información que nos puede ayudar a escribir nuestro CSS.

## 🎯 Nuestro objetivo

No necesitamos ser diseñadores.

Nuestro objetivo es aprender a **recibir un diseño y convertirlo en código**.

Por ejemplo:

```text
Figma
  ↓
¿Qué elementos necesito?
  ↓
HTML
  ↓
CSS
  ↓
JavaScript
  ↓
Página web
```

A lo largo del curso iremos haciendo este proceso con diferentes diseños y aumentando progresivamente la dificultad.
