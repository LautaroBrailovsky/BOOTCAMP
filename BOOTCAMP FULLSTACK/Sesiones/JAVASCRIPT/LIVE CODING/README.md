
## 💻 Live Codings

En esta sección se recopilan los proyectos y ejemplos desarrollados durante las sesiones de clase mediante *live coding*. Son ejercicios prácticos realizados por el profesor para mostrar conceptos, probar funcionalidades y construir pequeñas aplicaciones paso a paso.

Los proyectos pueden estar desarrollados con HTML, CSS y JavaScript, y pueden incluir maquetación, interactividad y otras funcionalidades básicas.

### 📄 Web CV — Currículum interactivo

Pequeño proyecto de una página web de currículum vitae desarrollado durante una sesión de *live coding*.

- **Repositorio:** [web-cv en GitHub](https://github.com/migueldonaire/web-cv)
- **Demo online:** [Ver Web CV](https://mddonaire-webcv.netlify.app/)
- **Tecnologías:** HTML, CSS y JavaScript.
- **Objetivo:** crear una página web de currículum y practicar la estructura, los estilos y la interactividad de una web.
